# 抖音短视频下载工具 - Windows 版

无水印、最高清晰度批量下载抖音视频的专业工具。

## 🎯 工具能力

### 核心功能
- **无水印下载**：下载的视频不含抖音水印，保持原始画质
- **最高清晰度**：自动选择最佳画质（支持 1080P+ 高清视频）
- **博主主页批量下载**：输入博主主页链接，一键获取所有作品
- **智能选择**：自动识别已下载视频，避免重复下载
- **分页加载**：每次加载 5 个视频，滑动自动加载更多

### 辅助功能
- **下载历史记录**：记录所有下载记录，绿色=未下载，灰色=已下载
- **收藏功能**：收藏喜欢的博主，方便快速访问
- **视频预览**：悬停预览视频内容，快速筛选
- **自定义下载目录**：支持自定义保存路径
- **实时下载进度**：显示当前下载任务进度，不含历史累计
- **Cookie 管理**：支持登录状态保持，获取更多内容

## 🚀 使用方法

### 方式一：直接使用 EXE（推荐，无需安装 Python）

1. **获取程序**：从 `dist` 目录获取 `douyin.exe` 文件
2. **运行程序**：双击 `douyin.exe`，程序会自动打开浏览器窗口
3. **开始使用**：粘贴博主链接，点击"获取作品"即可

### 方式二：使用源码运行（需要 Python）

#### 1. 环境要求
- Windows 10/11
- Python 3.7 或更高版本

#### 2. 安装依赖
```bash
pip install flask requests
```

#### 3. 启动程序

**方法 A：双击启动脚本**
- 双击 `start.bat` - 显示命令行窗口（便于查看日志）
- 双击 `启动下载器.vbs` - 后台运行（无窗口）

**方法 B：命令行启动**
```bash
python app.py
```

#### 4. 访问应用
程序启动后会自动打开浏览器，或手动访问：`http://127.0.0.1:5001`

打包完成后，在 `dist` 目录下会生成：
- `douyin.exe` - 主程序文件
- 无需其他依赖，可单独运行

### 打包说明
- 使用 `--windowed` 模式，无 CMD 窗口

- 自动打开浏览器功能已内置

## 📖 详细使用指南

### 首次使用
1. **获取博主链接**：复制抖音博主主页链接（如：`https://www.douyin.com/user/MS4wLjABAAAA...`）
2. **粘贴链接**：将链接粘贴到输入框
3. **获取作品**：点击"获取作品"按钮，等待视频列表加载
4. **选择视频**：勾选要下载的视频（可多选）
5. **开始下载**：点击"下载选中（X个）"按钮开始下载

### 设置下载目录
1. 点击右上角"⚙️ 设置"按钮
2. 点击"浏览"选择目标文件夹，或直接输入路径
3. 点击"保存"按钮

### Cookie 设置（可选）
1. 如果获取作品失败，系统会自动弹出 Cookie 输入框
2. 在浏览器中登录抖音后，导出 cookies
3. 将 cookie 内容粘贴到输入框并保存

### 视频预览
鼠标悬停在视频卡片上，点击播放按钮 ▶ 可预览视频内容。

### 收藏博主
获取作品后，点击"⭐ 收藏"按钮可将博主添加到收藏栏，方便下次快速访问。

## ❓ 常见问题

### Q: 获取不到视频列表怎么办？
A: 部分账号需要登录才能获取内容：
1. 在浏览器中登录抖音
2. 使用 Cookie Editor 插件导出 cookies
3. 将 cookie 内容粘贴到程序的 Cookie 设置中

### Q: 下载失败显示权限问题？
A: 请尝试：
- 选择程序目录下的文件夹作为下载目录
- 或选择用户文档目录（如 `Documents`）
- 避免使用系统盘根目录（需要管理员权限）

### Q: 程序启动后浏览器没打开？
A: 请手动访问 `http://127.0.0.1:5001`

### Q: 如何停止程序？
A: 
- 如果使用 EXE：打开任务管理器，结束 `douyin.exe` 进程
- 如果使用源码：关闭命令行窗口或按 `Ctrl+C`
