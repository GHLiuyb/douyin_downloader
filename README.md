# 抖音短视频下载工具 - Windows 版

无水印、最高清晰度批量下载抖音视频。

## 功能特点

- ✅ 无水印下载
- ✅ 最高清晰度（自动选择最佳画质）
- ✅ 博主主页批量下载
- ✅ 下载历史记录（绿色=未下载，灰色=已下载）
- ✅ 收藏功能
- ✅ 视频预览播放
- ✅ 自定义下载目录
- ✅ 整体下载进度条

## 系统要求

- Windows 10/11
- Python 3.7 或更高版本

## 安装步骤

### 方案一：使用打包版本（推荐，无需安装 Python）

1. 下载 `抖音视频下载器.exe`
2. 双击 `启动下载器.vbs` 即可运行

### 方案二：从源码运行（需要 Python）

#### 1. 安装 Python

如果尚未安装 Python，请访问 https://www.python.org/downloads/ 下载并安装。

**重要**：安装时请勾选 "Add Python to PATH" 选项。

#### 2. 运行程序

**方式一：双击启动（推荐）**

双击 `启动下载器.vbs` 文件：
- 无窗口后台运行
- 自动检测并安装依赖
- 自动打开浏览器

**方式二：命令行启动**

双击 `启动下载器.bat` 文件，或打开命令行执行：

```bash
python app.py
```

然后访问 http://127.0.0.1:5001

## 打包成可执行文件

如果你想将程序打包成单个 `.exe` 文件（方便分享给他人）：

### 1. 安装打包工具

```bash
python -m pip install pyinstaller
```

### 2. 运行打包脚本

双击 `build.bat`，或执行：

```bash
python -m PyInstaller --name="抖音视频下载器" --onefile --windowed --add-data "templates;templates" app.py
```

### 3. 获取打包结果

打包完成后，在 `dist` 目录下会生成：
- `抖音视频下载器.exe` - 可执行文件
- `启动下载器.vbs` - 启动脚本

将这两个文件复制到任意位置，双击 `启动下载器.vbs` 即可运行，无需安装 Python。

## 使用说明

### 首次使用

1. 复制抖音博主主页链接（如：`https://www.douyin.com/user/MS4wLjABAAAA...`）
2. 粘贴到输入框，点击"获取作品"
3. 选择要下载的视频（绿色复选框=未下载，灰色=已下载）
4. 点击"下载选中"

### 设置下载目录

1. 点击"⚙️ 设置"按钮
2. 输入自定义下载路径，如：`D:\Downloads\抖音视频`
3. 点击"保存"

设置后视频将下载到指定目录，不再保存到程序目录。

### 视频预览

鼠标悬停在视频卡片上，点击 ▶ 播放按钮可预览视频。

### 收藏博主

获取作品后，点击"❤️ 收藏"可将博主链接保存到收藏栏，方便下次快速访问。

## 常见问题

### Q: 提示"未检测到 Python"
A: 请安装 Python 3.7+，并确保安装时勾选了 "Add Python to PATH"。

### Q: 获取不到视频列表
A: 部分账号需要登录才能获取，请：
1. 在浏览器中登录抖音
2. 使用 Cookie Editor 插件导出 cookies
3. 保存为 `cookies.txt` 放在程序目录

### Q: 下载速度慢
A: 下载速度取决于网络环境，建议：
- 使用稳定的网络连接
- 避免同时下载过多视频

### Q: 如何停止程序
A: 
- 如果使用 .vbs 启动：打开任务管理器，结束 "python.exe" 进程
- 如果使用 .bat 启动：关闭命令行窗口即可
