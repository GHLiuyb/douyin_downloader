# 抖音视频下载器 - 项目架构文档

## 项目概述

这是一个基于 Python Flask 的抖音视频下载工具，支持无水印、最高清晰度批量下载。

## 技术栈

- **后端**: Python 3.7+ + Flask
- **前端**: 原生 HTML5 + CSS3 + JavaScript (ES6+)
- **打包工具**: PyInstaller
- **网络请求**: urllib (标准库，无需额外依赖)

## 核心模块说明

### 1. app.py 模块划分

#### 配置模块
- `BASE_DIR`: 程序根目录
- `SETTINGS_FILE`: 设置文件路径
- `HISTORY_FILE`: 下载历史文件路径
- `FAVORITES_FILE`: 收藏列表文件路径
- `COOKIE_FILE`: Cookie 文件路径
- `DEFAULT_DOWNLOAD_DIR`: 默认下载目录
- `get_download_dir()`: 获取当前下载目录（支持自定义）

#### 数据持久化模块
- `load_json()`: 加载 JSON 文件
- `save_json()`: 保存 JSON 文件
- `load_history()`: 加载下载历史
- `save_history()`: 保存下载历史
- `load_favorites()`: 加载收藏列表
- `save_favorites()`: 保存收藏列表
- `load_settings()`: 加载设置
- `save_settings()`: 保存设置

#### Cookie 处理模块
- `load_cookies()`: 加载 cookies.txt
  - 支持 JSON 格式（Cookie Editor 导出）
  - 支持 Netscape 格式
  - 支持简单键值对格式

#### 网络请求模块
- `make_request()`: 发起 HTTP 请求
- `resolve_share_url()`: 解析短链接
- `extract_sec_uid()`: 从 URL 提取用户 ID

#### 视频解析模块
- `extract_best_video_url()`: 提取最佳视频 URL（无水印）
- `extract_play_url()`: 提取播放 URL（带水印，用于预览）
- `get_user_videos_from_api()`: 从 API 获取视频列表
- `get_user_videos()`: 获取用户所有视频（支持分页）
- `get_video_detail()`: 获取单个视频详情

#### 下载模块
- `download_file()`: 下载文件（带进度）
- `download_video()`: 下载视频（异步，多线程）
- `download_tasks`: 全局下载任务状态字典

#### Flask 路由模块
- `/`: 首页
- `/api/fetch_videos`: 获取视频列表
- `/api/download`: 开始下载
- `/api/download_status`: 查询下载状态
- `/api/downloaded_file/<video_id>`: 下载已完成的文件
- `/api/history`: 获取下载历史
- `/api/clear_history`: 清除历史
- `/api/favorites`: 收藏管理（GET/POST/DELETE）
- `/api/settings`: 设置管理（GET/POST）
- `/api/open_downloads`: 打开下载目录
- `/downloads/<filename>`: 静态文件服务
- `/api/play/<video_id>`: 视频代理播放

### 2. index.html 模块划分

#### UI 组件
- **顶部栏**: Logo + 标题 + 设置按钮
- **收藏栏**: 收藏的博主快捷入口
- **输入区**: URL 输入框 + 获取按钮 + 收藏按钮
- **统计栏**: 视频总数/已下载/已选择
- **视频网格**: 5列网格布局，每卡片包含：
  - 缩略图
  - 复选框（绿色=未下载，灰色=已下载）
  - 播放按钮（悬停显示）
  - 标题
  - 时长
- **底部操作栏**: 全选/取消选择/下载/打开目录/设置
- **下载面板**: 整体进度条 + 各任务进度列表
- **设置弹窗**: 下载目录设置
- **视频预览弹窗**: 视频播放

#### JavaScript 模块
- **数据管理**: `allVideos`, `selectedVideos`, `activeTasks`, `favorites`
- **视频获取**: `fetchVideos()`, `loadFavorites()`
- **选择管理**: `toggleSelect()`, `selectAll()`, `deselectAll()`, `selectAllUndownloaded()`
- **下载控制**: `downloadSelected()`, `pollStatus()`, `updateDownloadPanel()`
- **预览播放**: `playPreview()`, `closePreview()`
- **设置管理**: `openSettings()`, `saveSettings()`, `resetDownloadDir()`
- **收藏管理**: `addFavorite()`, `removeFavorite()`, `renderFavorites()`
- **工具函数**: `showToast()`, `escapeHtml()`

## 数据流

```
用户输入 URL
    ↓
前端调用 /api/fetch_videos
    ↓
后端调用抖音 API (aweme/v1/web/aweme/post/)
    ↓
解析视频列表（去水印 URL、封面、时长等）
    ↓
返回前端渲染
    ↓
用户选择视频
    ↓
前端调用 /api/download
    ↓
后端创建异步下载任务（多线程）
    ↓
前端轮询 /api/download_status 获取进度
    ↓
下载完成，保存到本地目录
    ↓
更新下载历史
```

## 关键配置

### 抖音 API
- **列表接口**: `https://www.douyin.com/aweme/v1/web/aweme/post/`
- **详情接口**: `https://www.douyin.com/aweme/v1/web/aweme/detail/`
- **分页参数**: `max_cursor`, `count=20`

### 服务端配置
- **端口**: 5001
- **主机**: 0.0.0.0（允许外部访问）

### 文件编码
- 所有文本文件使用 UTF-8 编码
- JSON 文件使用 `ensure_ascii=False` 保存中文
