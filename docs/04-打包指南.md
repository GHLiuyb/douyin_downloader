# 打包指南

## 一、打包前准备

### 1. 安装依赖

```bash
# 安装 Flask
python -m pip install flask

# 安装 PyInstaller
python -m pip install pyinstaller
```

### 2. 测试程序

确保程序能正常运行：

```bash
python app.py
```

访问 http://127.0.0.1:5001 测试所有功能正常。

---

## 二、打包方法

### 方法一：使用 build.bat（推荐）

双击 `build.bat` 文件，自动完成：
1. 检查并安装依赖
2. 清理旧构建文件
3. 打包为可执行文件
4. 复制必要文件到输出目录

输出目录：`dist/`

---

### 方法二：手动打包

#### 1. 单文件打包（推荐）

```bash
python -m PyInstaller ^
    --name="抖音视频下载器" ^
    --onefile ^
    --windowed ^
    --add-data "templates;templates" ^
    --clean ^
    app.py
```

**参数说明**:
- `--onefile`: 打包为单个可执行文件
- `--windowed`: 不显示控制台窗口
- `--add-data "templates;templates"`: 包含模板文件
- `--clean`: 清理临时文件

#### 2. 复制必要文件

打包完成后，手动复制：

```bash
# 创建输出目录结构
mkdir dist\templates

# 复制模板文件
xcopy /s templates\* dist\templates\

# 复制启动脚本
copy 启动下载器.vbs dist\
copy 启动下载器.bat dist\

# 复制文档
copy README.md dist\
```

## 三、打包配置详解

### 1. 修改图标（可选）

准备 `.ico` 格式图标文件：

```bash
python -m PyInstaller ^
    --name="抖音视频下载器" ^
    --onefile ^
    --windowed ^
    --add-data "templates;templates" ^
    --icon=app.ico ^
    app.py
```

### 2. 排除不必要的模块（减小体积）

```bash
python -m PyInstaller ^
    --name="抖音视频下载器" ^
    --onefile ^
    --windowed ^
    --add-data "templates;templates" ^
    --exclude-module matplotlib ^
    --exclude-module numpy ^
    --exclude-module pandas ^
    app.py
```

### 3. 使用 UPX 压缩（进一步减小体积）

1. 下载 UPX: https://upx.github.io/
2. 解压到任意目录
3. 打包时指定 UPX 路径：

```bash
python -m PyInstaller ^
    --name="抖音视频下载器" ^
    --onefile ^
    --windowed ^
    --add-data "templates;templates" ^
    --upx-dir=C:\path\to\upx ^
    app.py
```

## 五、常见问题

### 1. 打包后提示"找不到 templates"

**原因**: `--add-data` 参数格式错误或路径不对

**解决方案**:
- Windows 使用分号 `;` 分隔: `--add-data "templates;templates"`
- Mac/Linux 使用冒号 `:` 分隔: `--add-data "templates:templates"`

### 2. 打包后文件很大（>100MB）

**原因**: PyInstaller 打包了很多不必要的依赖

**解决方案**:
```bash
# 使用虚拟环境（推荐）
python -m venv venv
venv\Scripts\activate
pip install flask pyinstaller
python -m PyInstaller --onefile app.py
```

### 3. 打包后运行闪退

**排查步骤**:
1. 先使用 `--console` 代替 `--windowed` 打包
2. 运行查看错误信息
3. 修复问题后再用 `--windowed` 打包

```bash
# 带控制台打包，便于调试
python -m PyInstaller --onefile --console app.py
```

### 4. 杀毒软件误报

**原因**: PyInstaller 打包的程序可能被误认为是病毒

**解决方案**:
- 将程序添加到杀毒软件白名单
- 或使用 `--onefile` 改为 `--onedir`（目录形式）

## 七、版本管理

### 修改版本号

在 app.py 中添加版本信息：

```python
__version__ = "1.0.0"

# 在首页路由中传递版本号
@app.route("/")
def index():
    return render_template("index.html", version=__version__)
```

### 打包命名

```bash
# 带版本号的打包
python -m PyInstaller --name="抖音视频下载器_v1.0.0" app.py
```

## 八、自动化打包（CI/CD）

### GitHub Actions 示例

```yaml
# .github/workflows/build.yml
name: Build

on: [push]

jobs:
  build:
    runs-on: windows-latest
    steps:
    - uses: actions/checkout@v2
    - uses: actions/setup-python@v2
      with:
        python-version: '3.9'
    - run: pip install flask pyinstaller
    - run: python -m PyInstaller --onefile --windowed --add-data "templates;templates" app.py
    - uses: actions/upload-artifact@v2
      with:
        name: 抖音视频下载器
        path: dist/*.exe
```
