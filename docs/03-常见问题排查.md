# 常见问题排查指南

## 一、启动问题

### 1. 提示"未检测到 Python"

**原因**: 系统未安装 Python 或 Python 未添加到 PATH

**解决方案**:
1. 访问 https://www.python.org/downloads/ 下载 Python 3.7+
2. **重要**: 安装时勾选 "Add Python to PATH"
3. 重新打开命令行或重启电脑

**验证**:
```bash
python --version
```

---

### 2. 提示"Flask 安装失败"

**原因**: 网络问题或 pip 配置问题

**解决方案**:
```bash
# 使用国内镜像源
python -m pip install flask -i https://pypi.tuna.tsinghua.edu.cn/simple

# 或升级 pip 后重试
python -m pip install --upgrade pip
python -m pip install flask
```

---

### 3. 端口 5001 被占用

**错误信息**: `Address already in use`

**解决方案**:
1. 查找占用进程:
   ```bash
   netstat -ano | findstr :5001
   ```
2. 结束进程（将 <PID> 替换为实际进程号）:
   ```bash
   taskkill /PID <PID> /F
   ```
3. 或修改 app.py 中的端口:
   ```python
   app.run(host="0.0.0.0", port=5002)  # 改为其他端口
   ```

---

## 二、获取视频问题

### 1. 提示"无法从链接中提取用户ID"

**原因**: URL 格式不正确

**正确格式**:
- `https://www.douyin.com/user/MS4wLjABAAAA...`
- `https://v.douyin.com/xxxxx` (短链接，会自动解析)

**错误格式**:
- `https://www.douyin.com/video/...` (这是视频链接，不是用户主页)
- `https://www.douyin.com/` (首页)

---

### 2. 提示"API 请求失败"或"未找到视频"

**可能原因**:
1. 网络连接问题
2. 该账号为私密账号
3. 需要登录 Cookie

**解决方案**:

**步骤 1**: 检查网络
```bash
ping www.douyin.com
```

**步骤 2**: 设置 Cookie（如账号需要登录）
1. 在浏览器中登录抖音
2. 安装 Cookie Editor 插件（Chrome/Edge 商店）
3. 导出 cookies 为 JSON 格式
4. 在项目目录创建 `cookies.txt` 文件
5. 粘贴导出的 JSON 内容

**Cookie 文件格式示例**:
```json
[
  {
    "name": "sessionid",
    "value": "xxxxxxxx",
    "domain": ".douyin.com"
  }
]
```

---

### 3. 获取到的视频列表为空

**排查步骤**:
1. 确认博主有公开视频
2. 检查 Cookie 是否过期
3. 查看控制台日志（运行 app.py 的窗口）

**调试命令**:
```bash
# 手动测试 API
python -c "
import urllib.request
import json

url = 'https://www.douyin.com/aweme/v1/web/aweme/post/?sec_user_id=YOUR_SEC_UID&count=20&aid=6383'
req = urllib.request.Request(url, headers={'User-Agent': 'Mozilla/5.0'})
resp = urllib.request.urlopen(req)
print(json.loads(resp.read()))
"
```

## 三、下载问题

### 1. 下载进度卡在 0%

**原因**: 视频 URL 失效或网络问题

**解决方案**:
1. 刷新页面重新获取视频列表
2. 检查网络连接
3. 查看控制台是否有错误日志

---

### 2. 提示"下载失败: HTTP Error 403"

**原因**: 抖音服务器拒绝了请求（可能需要 Cookie 或 Referer）

**解决方案**:
1. 确保已设置 cookies.txt
2. 检查 Cookie 是否过期（重新从浏览器导出）

---

### 3. 下载的文件无法播放

**原因**: 文件下载不完整或损坏

**排查**:
1. 检查文件大小是否正常（几 MB 到几十 MB）
2. 尝试用其他播放器（VLC）打开
3. 删除文件重新下载

---

### 4. 下载速度慢

**优化方案**:
1. 使用有线网络连接
2. 避免高峰期下载
3. 减少同时下载的视频数量
4. 检查是否有其他程序占用带宽

---

## 四、播放预览问题

### 1. 点击播放按钮无反应

**排查步骤**:
1. 检查浏览器控制台（F12）是否有错误
2. 确认视频有 `play_url` 或 `download_url`
3. 检查后端 `/api/play` 接口是否正常

**调试**:
```bash
# 测试代理播放接口
curl "http://127.0.0.1:5001/api/play/1234567890?url=https://v26-dy.ixigua.com/..."
```

---

### 2. 提示"无法直接播放，已打开视频页面"

**原因**: 抖音视频有 Referer 限制，后端代理播放失败

**解决方案**:
1. 检查 app.py 中的 `proxy_play` 函数
2. 确认 `Referer` 和 `User-Agent` 设置正确
3. 尝试更新 Cookie

---

## 五、设置问题

### 1. 设置下载目录后无法下载

**原因**: 目录不存在或没有写入权限

**解决方案**:
1. 确保目录路径正确（如 `D:\Downloads\抖音视频`）
2. 手动创建目录
3. 检查目录权限（右键目录 → 属性 → 安全）

---

### 2. 设置丢失

**原因**: settings.json 文件被删除或损坏

**解决方案**:
1. 检查项目目录下是否有 `settings.json`
2. 如损坏可删除，程序会自动重建

---

## 六、打包问题

### 1. PyInstaller 安装失败

```bash
# 使用国内镜像
python -m pip install pyinstaller -i https://pypi.tuna.tsinghua.edu.cn/simple
```

---

### 2. 打包后运行报错"找不到 templates"

**原因**: PyInstaller 未正确打包模板文件

**解决方案**:
确保使用正确的打包命令:
```bash
python -m PyInstaller --add-data "templates;templates" app.py
```

或使用 build.bat 自动打包。

---

### 3. 打包后文件太大

**优化方案**:
```bash
# 使用 UPX 压缩（需先安装 UPX）
python -m PyInstaller --upx-dir=/path/to/upx app.py

# 排除不必要的模块
python -m PyInstaller --exclude-module matplotlib --exclude-module numpy app.py
```

---

## 七、日志调试

### 开启详细日志

修改 app.py，在文件开头添加:
```python
import logging
logging.basicConfig(level=logging.DEBUG)
```

### 查看前端日志

浏览器按 F12 → Console 标签，查看 `[抖音下载器]` 开头的日志。
